# Excel Functions – Product Dataset

## 📌 Overview

This repository demonstrates the application of fundamental **Microsoft Excel functions** for data analysis and manipulation using a Product Dataset. It showcases essential Excel functions used to perform calculations, analyze data, categorize records, and extract information, helping transform raw data into meaningful insights for reporting and decision-making.

---

## 🎯 Objectives

- Perform statistical calculations
- Identify minimum and maximum values
- Categorize data using logical functions
- Perform conditional calculations
- Extract text from structured data
- Develop practical spreadsheet analysis skills

---

## 📂 Dataset Description

**Dataset Name:** Product Dataset

### Columns

- Product ID
- Product Name
- Brand Name
- Quantity
- Category
- Price

---

## 🛠 Excel Functions Used

| Category | Functions Used | Purpose |
|----------|----------------|---------|
| Statistical Functions | SUM, COUNT, AVERAGE | Calculate totals, record counts, and averages |
| Mathematical Functions | MIN, MAX | Identify minimum and maximum values |
| Logical Function | IF | Categorize products based on conditions |
| Conditional Functions | SUMIF, COUNTIF | Perform calculations based on specified criteria |
| Text Functions | LEFT, RIGHT, MID | Extract text from Product ID |

---

## 📋 Tasks Performed

### Statistical Analysis
- Calculated the total price of all products.
- Determined the total number of products.
- Calculated the average product price.

### Minimum & Maximum Analysis
- Identified the lowest product price.
- Identified the highest product price.

### Data Categorization
- Categorized products into **High Price** and **Standard Price** using the IF function.

### Conditional Analysis
- Calculated the total value of products in the Electronics category.
- Counted products priced below 100.

### Text Extraction
- Extracted **Day** from Product ID.
- Extracted **Month** from Product ID.
- Extracted **Country Code** from Product ID.
