# Excel Data Cleaning – Product Dataset

## 📌 Overview

This repository demonstrates data cleaning and transformation using **Microsoft Excel** and **Power Query Editor**. It showcases essential data preparation techniques required to convert raw, inconsistent data into a clean, structured, and analysis-ready dataset.

The dataset contains product information, including Product ID, Product Name, Brand Name, Quantity, Category, and Price.

---

## 🎯 Objectives

- Handle missing values
- Correct inconsistent data entries
- Remove duplicate records
- Split and merge columns
- Apply proper number formatting
- Use conditional formatting for visualization

---

## 📂 Dataset Description

**Dataset Name:** Product Dataset

### Columns

- Product ID
- Product Name
- Brand Name
- Quantity
- Category
- Price

---

## 🛠 Data Cleaning & Transformation

### Handling Missing Values
- Replaced missing values in the **Price** column using the average price within each category.

### Correcting Inconsistent Data
- Corrected inconsistent values using **Replace Values** in Power Query Editor.
- Example:
  - Electroni → Electronics

### Removing Duplicate Records
- Removed duplicate rows using the **Remove Duplicates** feature.

### Splitting and Merging Columns
- Split the **Product ID** column into Manufacturing Date and Country Code.
- Merged **Brand Name** and **Product Name** into a new **Product Brand** column.

### Number Formatting
- Formatted **Price** as Currency.
- Formatted **Manufacturing Date** as DD-MM-YYYY.

### Conditional Formatting
- Applied **Data Bars** to the Price column.
- Highlighted records where **Category = Electronics**.
