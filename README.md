# Data-Analysis-and-Preparation-using-Microsoft-Excel-and-Power-Query

## 📌 Overview

This repository demonstrates practical **Microsoft Excel** and **Power Query** skills for data analysis, cleaning, and transformation using a Product Dataset. It showcases Excel functions, data preprocessing techniques, and Power Query transformations to convert raw data into a clean, structured, and analysis-ready dataset.

---

## 📂 Repository Contents

### 📊 Excel Functions
- Statistical Functions (SUM, COUNT, AVERAGE)
- Mathematical Functions (MIN, MAX)
- Logical Functions (IF)
- Conditional Functions (SUMIF, COUNTIF)
- Text Functions (LEFT, RIGHT, MID)

### 🧹 Data Cleaning & Transformation
- Handle Missing Values
- Correct Inconsistent Data
- Remove Duplicates
- Split & Merge Columns
- Number Formatting
- Conditional Formatting
- Power Query Transformations
